## 1. 我们要解决什么

部署时只使用目标前进速度和本体感知历史，让高层策略决定采用哪种步态。
评价标准不是“是否出现多种步态”，而是相对固定小跑，是否改善速度跟踪、
稳定性、接触安全或能耗。

## 2. 当前已经实现

```text
目标速度 + 本体感知历史
        ↓
学生历史编码网络
        ↓
高层步态选择器
        ↓
双脚跳 / 小跑 / 跳跃 / 踱步
        ↓
预训练 WTW 低层控制器
```

- 训练时教师读取干净物理量，但不读取地形编号、任务编号或目标步态答案。
- 部署侧学生只依赖目标速度与本体感知历史。
- 平地和上坡使用同一套物理奖励。
- 当前汇报模型只选择离散步态，连续参数使用默认值。
- 已建立与强制小跑使用相同环境、速度和随机种子的严格成对评测。

## 4. 当前最可靠结论

- 平地上，策略超过 99.6% 的时间选择小跑，表现与固定小跑基本等价。
- 上坡 1.0 和 1.5 m/s 时，策略主要使用双脚跳。
- 中速上坡相对固定小跑具有更高综合得分、更低速度误差、更低接触滑移和更低冲击。
- 上述改善以更高机械功率为代价。
- 上坡 2.0 m/s 不如固定小跑，说明当前方法存在明确适用边界。

建议汇报结论：

```text
仅依赖目标速度和本体感知历史，高层策略能够在平地和上坡之间形成条件相关的
步态选择；在中速上坡上相对固定小跑改善跟踪与接触安全，但增加机械功率，
且这一收益不能推广到高速上坡或所有未见地形。
```

## 5. 尚未实现

- 没有实现可靠的连续步态参数自适应。
- 没有证明所有地形上都优于固定小跑。
- 横向推扰上的未见场景泛化失败。
- 踏石只有很小且伴随安全代价的探索性改善。
- 没有完成仿真到实机迁移。
- 统一奖励是经过一致性检查的候选物理目标，不是普遍正确的真值。

## 7. 视频使用限制

`videos_all_terrains_1080p` 中五段视频均为单环境、确定性输出，并且都选择了
小跑。它们可以展示地形和仿真运行情况，但不能用来证明中速上坡的统计性步态
分化。核心结论必须以 32 个并行环境、三个随机种子的成对评测为依据。

若汇报需要展示上坡双脚跳，应重新录制一个与批量评测采样规则一致、同时保存
步态概率和随机种子的代表案例，不能人为强制目标步态并冒充策略输出。

## 8. 汇报后开发顺序

1. 修正可视化采样，使视频与正式评测使用相同的动作选择口径。
2. 使用多个训练随机种子复核平地/上坡结论，而不只增加评测随机种子。
3. 研究连续参数缺少有效收益的原因，先逐个参数验证，不同时开放全部参数。
4. 在不增加地形编号或步态答案的前提下，提高未见地形上的历史状态表征。
5. 最后再进行噪声、延迟和实机验证。
