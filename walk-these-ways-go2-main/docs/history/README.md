# 历史文档

本目录保存项目早期交接记录、逐轮实验日志和七月汇报快照，用于追溯实验过程。
这些文档不再代表项目的最终判断，也不建议作为第一次阅读入口。

当前阅读顺序：

1. 仓库根目录 `README.md`：项目总体介绍；
2. `CURRENT_PROJECT_STATUS.md`：截至归档时的可信结论；
3. `ARCHIVE_AND_REPRODUCIBILITY.md`：模型、环境和复现边界；
4. `PROJECT_INDEX.md`：全仓库导航；
5. 只有需要追查具体实验时，才阅读本目录文件。

## 文件说明

| 文件 | 性质 |
|---|---|
| `ACTIVE_PROJECT_CONTEXT.md` | 早期至中期的完整技术上下文 |
| `CURRENT_GAIT_ADAPTATION_PLAN.md` | 后续逐轮实验、命令和即时判断 |
| `CONVERSATION_HANDOFF_20260608.md` | 早期对话交接快照 |
| `CONVERSATION_HANDOFF_20260611.md` | 早期对话交接快照 |

| `DETAILED_PROJECT_REVIEW_20260723.md` | 七月详细技术复盘 |

历史文件中的命令默认从仓库根目录执行。文件内的旧判断可能已经被八月实验修正，引用时
应以根目录 `CURRENT_PROJECT_STATUS.md` 为准。
