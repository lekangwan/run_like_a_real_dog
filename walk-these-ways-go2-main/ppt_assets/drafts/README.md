# PPT 流程图草稿

本目录保存已经被替换的流程图和重复预览，避免它们与当前 PPT 素材混在一起。
这些文件只用于追溯，不代表最终实现或最终框架。

| 文件 | 状态 | 原因 |
|---|---|---|
| `p2_pipeline.svg` | 禁止用于汇报 | 包含后来删除的 14 维物理量解码器，并把预测物理量与隐变量同时输入策略，结构重复。 |
| `p2_pipeline_preview.png` | 禁止用于汇报 | `p2_pipeline.svg` 的旧版预览。 |
| `p2_pipeline_current_academic.png` | 历史设计稿 | 内容过密，仍包含物理量解码与重建分支。 |
| `p2_pipeline_current_compact_preview.png` | 重复预览 | 当前紧凑版的另一尺寸导出，不作为正式素材。 |

当前应使用上一级目录中的：

```text
p2_pipeline_current_compact.svg
```

该文件描述的是复盘后重新设计的展示框架。项目没有使用该完整新版结构重新训练，
因此 PPT 中应标为“改进框架设计”，不能与七月模型的实验结果混为一谈。
